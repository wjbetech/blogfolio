Inspired by IRC, Discord, and WhatsApp, Cabin Chat is a small chat server meant to run on a home lab around the clock. The backend is Go with PostgreSQL for persistence; Docker Compose handles the local database during development. Auth, messaging, reactions, and uploads are being wired in phase by phase.
