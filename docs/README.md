# docs/

This directory contains all operational, architectural, and workflow documentation for **blogfolio**.

## Index

| File | What it covers |
| --- | --- |
| [architecture.md](./architecture.md) | Tech stack, app routes, Contentlayer build pipeline, data flow |
| [hosting.md](./hosting.md) | Homelab setup -- Proxmox, Docker, Cloudflare Tunnel, domain |
| [deployment.md](./deployment.md) | GitHub Actions auto-deploy on push to master |
| [media.md](./media.md) | Image conventions, folder structure, fallback rules |
| [seo.md](./seo.md) | What already ships (sitemap, robots, RSS, JSON-LD, OG) and what's still needed |

| [content.md](./content.md) | Writing and publishing posts and projects -- frontmatter specs, workflow |
| [maintenance.md](./maintenance.md) | Changelog/release flow, monthly content sweep, docs audit cadence |
| [roadmap.md](./roadmap.md) | Current status and planned work phases |
| [todo.md](./todo.md) | The immediate next steps -- start here when picking up work |

## Quick orientation

- **Adding a blog post or project?** Start with [content.md](./content.md).
- **Setting up the server or deploy pipeline?** See [hosting.md](./hosting.md) and [deployment.md](./deployment.md).
- **Picking up where work left off?** Open [todo.md](./todo.md).
- **Making a UI or style change?** Read [design-system.md](./design-system.md) first.
