# Admin Dashboard Scope (Deferred)

The current product direction is a static Contentlayer-driven blogfolio. An admin dashboard is optional and not required for MVP delivery.

## Deferred Until Needed

- Content editing workflow uses Git + PR review for now.
- No runtime write APIs are required for public content.
- Revisit this doc when editorial needs outgrow PR-based content updates.

## Future Considerations

- Evaluate Git-backed CMS options before building a custom dashboard.
- If custom admin is introduced, define clear auth, validation, and audit requirements.
