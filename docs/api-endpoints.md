# API Endpoints Scope (Deferred)

This project currently serves public content from Contentlayer-generated static data. Runtime CRUD endpoints for posts/projects are not part of the MVP roadmap.

## Current State

- Public pages read from `allPosts` / `allProjects` generated by Contentlayer.
- No database-backed API is required for public rendering.

## Optional Future APIs

- Add write-enabled endpoints only if a dedicated admin backend/CMS is adopted.
- If introduced, require auth, validation, sanitization, and rate limiting from day one.
